# Main Quest 2 인수인계: 인바디 결과지 → 운동 루틴 추천 PoC

> Cowork 대화에서 정리한 내용입니다. Claude Code에서 이 파일을 읽고 이어서 진행해 주세요.

## 과제 요약
- 과정: AI Agent 서비스 개발자 과정, Main Quest 2 (내 도메인에서 AI 개선 지점을 찾아 PoC 만들기)
- 제출: GitHub 저장소 (문제 정의서, PoC 코드/노트북 + 모델 선정 근거, 개선 효과 검증 + 실패 사례, README + 시연 자료)
- 평가 기준: ① 문제 정의 ② 모델 선정 근거 ③ 동작하는 PoC(입력 → AI 처리 → 출력, 재현 가능) ④ 기존 방식 대비 검증(정량/정성) ⑤ 한계·다음 단계·추가 시도
- 마감 여유: 2일 이내

## 결정된 사항 (인터뷰 결과)
| 항목 | 결정 |
|---|---|
| 도메인 | 기존 '나만의 헬스도감' (HTML/JS 웹페이지) 확장 |
| 기능 | 인바디 결과지 사진을 읽고 운동 루틴 추천 |
| 데이터 | 실제 결과지 없음 → 가상 체성분 결과지 이미지 + 정답 JSON을 직접 생성 (개인 건강정보 보호가 이유이며, 브랜드 로고는 쓰지 않음) |
| 수치 추출 방식 | OCR와 비전 LLM 비교: EasyOCR/PaddleOCR + 정규식 vs Gemini Flash vs Claude 비전 |
| 실행 환경 | Gemini·Claude API 키 있음, Colab 사용 |
| 추천 방식 | 헬스도감에 있는 운동 목록 안에서만 LLM이 루틴을 구성하고, 도감에 없는 운동은 코드에서 한 번 더 걸러냄 |
| 운동 루틴 skill 문서 | 진행 중에 추천 단계에서 반영하기로 함 (아직 미작성) |

## 파이프라인
결과지 사진 → ① 수치 추출 (모델 3종 비교) → ② 수치 JSON → ③ 도감 운동 데이터 기반 루틴 추천 (구조화된 JSON 출력) → ④ 헬스도감 화면에 표시

## 성공 기준 (초안)
- 핵심 8개 필드 추출 정확도 95% 이상: 체중, 골격근량, 체지방량, 체지방률, BMI, 기초대사량, 점수, 복부지방률
- 수기 입력 약 2분 → PoC 10초 이내
- 추천된 운동이 100% 도감 안에 있음

## 2일 계획
**Day 1**
1. 문제 정의서 작성 (도메인 / 현재 문제 / 개선 가설 / 대상 사용자: 나 + 헬스 입문자 / 성공 기준)
2. 가상 결과지 생성기: HTML 템플릿 → 이미지 10~15장 + ground_truth.json. 일부는 기울기·흐림·그림자·저해상도를 넣어 폰 촬영을 흉내 냄
3. Colab에서 모델 3종 비교: 필드 정확도, 장당 처리 시간, 비용, 흐린 사진에서의 성능 → 비교표 = 모델 선정 근거

**Day 2**
4. 루틴 추천: 도감 운동 JSON + 추출한 수치 → LLM → JSON 루틴 → 도감에 없는 운동 필터링
5. 헬스도감 연결: 정적 HTML에 API 키를 넣으면 노출되므로 (a) 사용자가 키를 입력하는 칸을 만들거나 (b) Colab + Gradio로 시연하고 도감에는 결과 표시 화면만 둠
6. 검증 문서 (시간·정확도 비교, 실패 사례 3건) + README (실행 방법, 스크린샷/GIF) + 한계·다음 단계 (실제 결과지 검증, 브랜드별 양식 차이, 키 보안, 의료 조언 아님 고지)
